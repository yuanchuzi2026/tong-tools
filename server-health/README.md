# Server Health Dashboard 🖥️

> 一行命令安装，实时查看服务器状态

## 安装

```bash
# 下载安装
curl -sL https://raw.githubusercontent.com/yuanchuzi2026/tong-tools/main/server-health/server-health.sh -o server-health.sh
chmod +x server-health.sh
sudo ./server-health.sh --install

# 或者直接运行
bash server-health.sh --run
```

## 用法

| 命令 | 说明 |
|------|------|
| `server-health --run` | 单次查看状态 |
| `server-health --watch` | 实时监控（5秒刷新） |
| `server-health --install` | 安装到系统 |
